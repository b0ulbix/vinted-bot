Vitesse de surveillance

Temps entre deux vérifications de toutes tes catégories. Plus c'est court, plus tu es rapide, mais plus Vinted risque de bloquer un moment. Entre 10 et 30 secondes, c'est idéal.

🔥 Bonnes affaires

Le bot estime la cote de chaque nouvelle annonce : prix Cardmarket pour les cartes Pokémon, prix médian des annonces similaires sur Vinted pour le reste (même marque, même type, même taille). En dessous du seuil, c'est une bonne affaire.

Discord (salon par défaut)

Utilisé pour les catégories qui n'ont pas leur propre salon.

  1. Sur Discord : clic droit sur un salon → Modifier le salon.
  2. Intégrations → Webhooks → Nouveau webhook → Copier l'URL du webhook.
  3. Colle-la ici, enregistre, puis clique sur « Tester ».

Telegram

  1. Dans Telegram, écris à @BotFather → /newbot → choisis un nom. Il te donne un token.
  2. Colle le token ici et enregistre.
  3. Envoie un message à ton bot, puis clique sur « Trouver mon chat ID ».
